# 🚆 Train Consist Management App

## 📌 Overview
The Train Consist Management App is a Java-based console application that simulates how railway systems manage train compositions. It demonstrates various data structures, algorithms, and real-world constraints using multiple use cases.

---

## ⚙️ Features (Use Cases)

- UC1: Initialize Train
- UC2: Add Passenger Bogies (ArrayList)
- UC3: Unique Bogie IDs (HashSet)
- UC4: Ordered Train (LinkedList)
- UC5: Ordered + Unique (LinkedHashSet)
- UC6: Bogie-Capacity Mapping (HashMap)
- UC7: Sorting using Comparator
- UC8: Filtering using Streams
- UC9: Grouping using Collectors
- UC10: Total Capacity using reduce()
- UC11: Regex Validation
- UC12: Safety Validation using allMatch()
- UC13: Performance Comparison
- UC14: Custom Exception Handling
- UC15: Runtime Exception Handling
- UC16: Bubble Sort
- UC17: Arrays.sort()
- UC18: Linear Search
- UC19: Binary Search
- UC20: Defensive Programming (Exception Handling)
